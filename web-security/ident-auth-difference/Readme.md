# [Web-security] Разница между идентификацией, аутентификацией и авторизацией 🌟


## Эти три понятия часто путают, но у каждого из них своя роль в системе безопасности.

### Идентификация – определение пользователя (кто он?)
Пример: ввод логина или e-mail.

### Аутентификация – проверка личности (доказательство, что это действительно он)
Пример: ввод пароля, скан отпечатка пальца, SMS-код и т. д.

### Авторизация – предоставление прав доступа (что он может делать?)
Пример: разрешение на редактирование контента (админ-доступ).

## ❕ Простая аналогия
Вы хотите попасть в клуб, но на входе есть фейсконтроль:
- Идентификация → Охранник спрашивает ваше имя.
- Аутентификация → Вы показываете паспорт или пропуск.
- Авторизация → Охранник решает, можно ли вам в VIP-зону или только в общий зал.

## ❔ Какие бывают виды аутентификации?
1. По знанию (что вы знаете?)
— Пароль
— PIN-код
— Секретный вопрос

2. По владению (что у вас есть?)
— Токен
— Одноразовый код (SMS, e-mail)
— Электронная цифровая подпись (ЭЦП)

3. По биометрии (кто вы?)
— Touch ID (отпечаток пальца)
— Face ID (распознавание лица)
— Скан радужки глаза

4. Двухфакторная аутентификация (2FA)
Комбинация "что вы знаете?" + "что у вас есть?"
Пример: пароль + SMS-код.
